## Contributing
<a id="how-to-contribute"></a>

Want to add a badge or another resource to GitBox? 💜

1. Read the [CONTRIBUTING.md](https://github.com/raphaelamonteiro/gitbox/blob/main/CONTRIBUTING.md).
2. Add your resource to the appropriate category.
3. Keep resources in alphabetical order.
4. Open a pull request.

### 🏷️ Badge format

When adding a badge, use:

- `{TEXT}` — the text displayed on the badge.
- `{HEX-COLOR}` — the badge color, without `#`.
- `{LOGO-NAME}` — the logo name from Simple Icons.

> ⚠️ Please keep badges in alphabetical order within each category.
