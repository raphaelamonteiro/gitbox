# Contributing to GitBox

 Thanks for your interest in contributing to GitBox! 💙

 GitBox is an open-source collection of resources for GitHub, including badges, themes, templates, banners, widgets, and more.

 There are many ways to contribute — you can add a resource, improve existing ones, fix documentation, or suggest new ideas.

 ## 📦 Adding a resource

 Before adding a new resource:

 - Make sure it fits the purpose of GitBox.
- Check that a similar resource doesn't already exist.
- Make sure you have the right to distribute the resource.
- Follow the structure and naming conventions of the category you're contributing to.

 ### Adding a new resource

 1. Fork the repository.
2. Create a new branch for your changes.
3. Add your resource to the appropriate directory.
4. Update the relevant documentation or index if needed.
5. Make sure everything is formatted correctly.
6. Open a pull request.

 ## 🎨 Improving existing resources

 You can also contribute by:

 - Fixing broken resources or links.
- Improving templates.
- Updating themes.
- Improving documentation.
- Fixing typos or formatting.
- Suggesting new categories or features.

 ## 💡 Suggestions

 Have an idea for GitBox?

 Open an issue and describe:

 - What you'd like to add or change.
- Why it would be useful.
- Any examples or references that might help.

 ## 🔀 Pull requests

 Please keep pull requests focused on one change whenever possible.

 A good pull request should:

 - Have a clear title.
- Explain what was changed.
- Explain why the change was made.
- Include any relevant screenshots or examples.

 You can also check the [PR Template](PR-TEMPLATE.md).

 Please be respectful and constructive when reviewing or discussing contributions.
